# Англійський клуб · Campus Odesa — запуск сайту

У папці два файли:

- `index.html` — готовий сайт (усі фото вже всередині файлу, нічого більше не потрібно)
- `apps-script.gs` — код для Google-таблиці, який приймає анкети

---

## Крок 1. Таблиця й скрипт (5 хвилин)

1. Створи порожню Google-таблицю, назви «Англійський клуб — заявки».
2. З адреси таблиці скопіюй ID: `docs.google.com/spreadsheets/d/`**`ЦЕЙ_ID`**`/edit`
3. У таблиці: **Розширення → Apps Script**. Видали те, що там є, встав вміст `apps-script.gs`.
4. У рядку `const SHEET_ID = '...'` встав свій ID. Збережи (Ctrl+S).
5. **Розгорнути → Новий розгорток → Веб-додаток**:
   - Виконувати як: **Я**
   - Хто має доступ: **Усі**
   
   Натисни «Розгорнути», дозволь доступ, скопіюй посилання виду
   `https://script.google.com/macros/s/AKfy..../exec`

## Крок 2. Вставити посилання в сайт (1 хвилина)

Відкрий `index.html` у будь-якому текстовому редакторі, знайди рядок:

```js
var SHEET_ENDPOINT = "ВСТАВ_СЮДИ_ПОСИЛАННЯ_НА_APPS_SCRIPT";
```

Встав туди посилання з кроку 1 і збережи файл.

## Крок 3. Викласти сайт (5 хвилин)

Найпростіше — **Netlify Drop**:

1. Відкрий https://app.netlify.com/drop
2. Перетягни туди папку з `index.html`
3. Сайт одразу отримає адресу виду `random-name.netlify.app` — її можна змінити в налаштуваннях сайту (Site configuration → Change site name).
4. Якщо є домен (наприклад, `club.campus.org.ua`) — Domain management → Add custom domain, далі Netlify підкаже, який CNAME додати в DNS.

Альтернативи: Vercel, GitHub Pages, Cloudflare Pages — принцип той самий.

## Крок 4. Перевірка

Відкрий сайт, заповни анкету тестовими даними, натисни «Відправити». Рядок має з'явитися в таблиці протягом кількох секунд.

Якщо не з'явився:
- перевір, що в кроці 1 стояло «Хто має доступ: Усі»;
- перевір, що посилання закінчується на `/exec`, а не на `/dev`;
- після будь-якої зміни коду скрипта треба зробити **новий розгорток** (або «Керувати розгортками → редагувати → Нова версія»).

---

## Що далі

- Оновити сторінку = замінити `index.html` і перетягнути папку в Netlify ще раз.
- Заявки можна сортувати й фільтрувати прямо в таблиці; для сповіщень можна додати в Apps Script `MailApp.sendEmail(...)` — скажи, допоможу.

---

## Як саме сайт надсилає анкету

Apps Script відповідає редіректом на інший домен, тому браузер не дає прочитати відповідь (класична помилка `Failed to fetch`). Тому сторінка надсилає дані у режимі `no-cors`: запит доходить до скрипта, але відповідь браузер не показує. Наслідок — сторінка завжди показує подяку, навіть якщо скрипт із якоїсь причини не спрацював. Тому після кожної зміни скрипта варто один раз протестувати анкету й перевірити, що рядок з'явився в таблиці.
